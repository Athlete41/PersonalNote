# Agent 协作经验

1. **大部分 Agent 不会主动暴露它的边界和问题。** 它不知道自己不知道，漏了东西也不会主动问。所以你得主动——用 [[方法/交互式学习法]] 摸清它的行为规律再协作，主动检查它可能漏掉的东西。

2. **术语对齐很重要。** Agent 偏向主流术语，对自创或与主流冲突的术语适应性弱。而且你的术语在它的临时上下文里，不在长期记忆中——换一轮对话它可能又偏回主流理解。需要提前对齐、反复确认，不能指望它记住你的用法。

3. **Agent 适合做认知协作的镜子。** 你的大部分思考工作都可以跟它讨论协商，防局部最优；换一个 Agent 审视同一问题，相当于换个角度，效果类似。但最终决策必须是你。

4. **生成式任务是具象化过程，有随机性。** 不信任 Agent 落地能力的地方，提前给例子做锚点，缩小它的随机空间。

总的来说，把 Agent 当协作的人——陌生时期试探、熟悉后有信任区、关键点和坑像教同事一样教给它、不懂的可以问、它也能反过来教你。记住第 1 条：它不会主动开口，你得主动。
