# 抽象化

## 定义

抽象化是从高维向量空间到低维向量空间的映射。

- 输入维度 M，输出维度 N，且 **N ≤ M**
- 自由度变化：不变或减少（由维度下降可推出）

$$
f: \mathbb{R}^M \rightarrow \mathbb{R}^N, \quad N \leq M
$$

## 本质

抽象化的本质是**降维映射**。输入是 M 维向量，输出是 N 维向量，N 不大于 M，自由度不增加。

## 示例

### 注意力（掩码降维）

视野中有多个对象，施加掩码只保留其中一块区域，其余置零。

```
输入：完整画面的高维向量                    输出：仅保留被关注区域的低维向量
┌─────┬─────┐      Apply Mask      ┌─────┬─────┐
│ ■■  │     │     ───────────→     │ ■■  │  0  │
│ ■■  │  ●  │                      │ ■■  │  0  │
└─────┴─────┘                      └─────┴─────┘
```

### 比较（差分提取）

比较两个对象的长度，提取出差分关系。

```
A = 5
B = 3       →  比较(A, B) = 2    →  "A 偏大"
```

差分结果是一个低维值（标量），反映了高维输入（两个对象）之间的关系。
