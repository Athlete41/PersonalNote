# 类比与联想

## 定义

联想是从一个概念或感知出发，激活另一个概念或感知的认知过程。

## 可能的计算本质

联想可能是[[特征提取]]、[[比较]]、[[注意力]]、[[抽象化]]与[[具象化]]等认知功能复杂耦合后涌现出来的——提取当前概念的特征，与记忆中的节点匹配，或通过具象化展开场景后再由注意力捕获新线索。但具体的耦合方式我们并不确知。

## 路径

联想可以沿不同路径发生：

### 1. 基于特征匹配

将当前概念的特征与记忆网络中的节点进行匹配，激活相似节点。

```
输入："苹果" → 特征 [圆形, 红色, 甜] → 匹配 → 输出："梨"（形状、颜色相似）
```

### 2. 具象化→注意力转移→抽象化

从当前概念展开为具体场景，注意力被场景中的某个细节捕获，再提取为新概念。

```
输入："飞机" → 具象化为无人机画面 → 注意力被"材质"捕获 → 输出："塑料"
```

在这种路径中，联想的起点与终点之间没有直接的相似性，它们通过一个被具象化展开的中间场景连接起来。

## 性质

1. **自发性**：联想可以自动发生，不需要主动发起。
2. **路径多样性**：联想可以通过特征匹配直接完成，也可以通过具象化→注意力转移→抽象化的路径完成。
3. **背景依赖性**：联想的路径取决于当前注意力焦点和已有连接强度。
