# 整体与局部认知

## 定义

整体与局部认知，是将感知场中的多个元素视为一个整体，或将一个整体分解为多个局部的认知过程。它是架构自带的能力，自然而然发生，不需要后天学习。

## 可能的计算本质

整体与局部认知可能涉及[[注意力]]、[[../基础/抽象化|抽象化]]和[[../基础/具象化|具象化]]。

## 两个方向

### 整体化

将视野中的多个元素自动视为一个整体——不关注每个像素，而是直接把它们看作一个单元。多个元素被压缩为一个符号，细节被暂时悬置。

#### 示例：模型化/概念化

整体化也发生在多维度经验之间——声音、图像、触感、时序、交互等不同维度的信息被压缩为一个符号。该符号保留了所涉及维度的索引，定义了可以从哪些维度通过[[../基础/具象化|具象化]]展开。

```
                     ┌──────┐
                     │ 无人机 │
                     └──────┘
                        │
        ┌───────┬───────┼───────┬───────┐
        ▼       ▼       ▼       ▼       ▼
      图像    声音    触感     时序    交互
    (有)     (有)    (有)    (有)    (无)
```

每个符号只编码部分维度，不覆盖全部。不同符号的模型范围不同——"无人机"包含图像、声音、触感、时序但不包含交互；"苹果"包含图像和触感但不包含声音和时序。

### 局部化

从整体出发，展开其构成部分——一个整体符号被展开为多个子单元，每个子单元同样可以被视为一个整体，继续展开为更细的局部。

```
飞机             ← 整体
├── 机翼         ← 局部（也是子整体）
│   ├── 翼尖     ← 更细的局部
│   └── 襟翼
├── 发动机
└── 起落架
```

## 性质

1. **自动性**：整体化可以在感知层自动完成，不需要主动调用。
2. **可逆性**：整体化与局部化可以交替进行。
3. **嵌套性**：局部本身也可以被视为整体，继续展开。
4. **非语言性**：不依赖语言也能感知整体与局部。
