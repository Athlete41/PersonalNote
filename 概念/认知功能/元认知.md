# 元认知

## 定义

元认知是将注意力投向认知过程的输入与输出之间，对两者之间的变换进行猜测的认知活动。它不直接操作外部对象，而是操作认知过程本身——"关于认知的认知"。

## 可能的计算本质

元认知可能涉及[[注意力]]和[[比较]]——将注意力同时投向输入与输出，通过比较两者的差异来推断中间变换的性质。

## 示例

### 判断自己是否理解

```
输入：一篇关于相对论的文章
输出：无法用自己的话复述

      ↓ 注意力同时关注输入和输出
      ↓ 比较：输入量大而输出几乎为零
      ↓ 猜测：中间变换出了问题, "我没理解"
```

### 估算难度

```
输入：一道数学题
输出：已有解题思路

      ↓ 注意力关注输入到输出的过程
      ↓ 比较：输入→输出的变换是否流畅
      ↓ 猜测："这道题对我来说很简单"
```

## 性质

1. **二阶性**：元认知的操作对象不是外部世界，而是认知过程本身。
2. **基于猜测**：元认知并不直接"看到"过程内部，而是从输入和输出的关系中推断。
3. **可用来调节**：元认知的猜测结果可以反过来影响认知策略（如"太难了，换一种方法"）。
