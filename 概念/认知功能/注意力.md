# 注意力

## 定义

注意力是在输入向量上施加掩码（Mask），选择性地保留部分维度、置零或衰减其余维度的操作。

$$
\mathbf{y} = \mathbf{M} \odot \mathbf{x}
$$

其中：
- $\mathbf{x}$ 为输入向量
- $\mathbf{M}$ 为掩码向量（元素值为 0 或 1，也可为连续值）
- $\odot$ 为逐元素乘积
- $\mathbf{y}$ 为输出向量，$\dim(\mathbf{y}) \leq \dim(\mathbf{x})$

## 可能的计算本质

注意力属于[[../基础/抽象化|抽象化]]——通过掩码对输入向量的各维度加权，选择性保留被关注的维度，是一个降维过程。

## 示例

### 视野区域选择

视野中有两个对象，施加掩码只关注左侧对象。

```
输入向量                          掩码                输出向量
┌─────┬─────┐                  ┌─────┬─────┐         ┌─────┬─────┐
│ 0.2 │ 0.8 │     ⊙            │  1  │  0  │    =    │ 0.2 │  0  │
│ 0.5 │ 0.3 │                  │  1  │  0  │         │ 0.5 │  0  │
└─────┴─────┘                  └─────┴─────┘         └─────┴─────┘
  关注对象A                      保留A，屏蔽B             仅保留A
```

高维输入经掩码后输出低维向量（被屏蔽部分置零）。

### 数值衰减

注意力强度不一定是二值的（0 或 1），也可以是连续的——对部分维度不完全置零，只做衰减。

```
输入向量                 连续掩码                     输出向量
[0.2, 0.8, 0.5, 0.3]    ⊙  [1.0, 0.1, 0.0, 0.6]    =  [0.2, 0.08, 0, 0.18]
```
