# 情景记忆

## 定义

### 经典定义（Tulving, 1972）

> 情景记忆是"接收和存储关于时间日期的事件、情节以及这些事件之间的时空关系信息的记忆系统"。

### 自知意识与心理时间旅行（Tulving, 1985）

Tulving 后来认识到仅凭 What-Where-When 不足以定义情景记忆。他提出情景记忆的核心特征是**自知意识（Autonoetic Consciousness）**——即个体在回忆时能主观地"重新经历"过去的事件，并意识到那是自己过去经历的一部分。与之相对：

- **无觉知意识（Anoetic Consciousness）**：程序性记忆的特征，纯粹的操作，无反思
- **觉知意识（Noetic Consciousness）**：语义记忆的特征，知道事实但不伴随重新体验

自知意识使得**心理时间旅行（Mental Time Travel）**成为可能——个体可以在主观时间中向回回溯（回忆）或向前投射（想象未来场景）。

## 核心特征（Tulving 框架）

1. **自知意识**：回忆时伴随"我经历过"的主观体验
2. **自我**：记忆归属明确的自我主体
3. **主观时间感**：事件在个人时间轴上的定位

这四个信息被同时编码，构成事件的基本框架：
- **What**（发生了什么）
- **Where**（在哪里发生）
- **When**（何时发生）
- **Autonoetic**（伴随自我体验）

## 神经基础

- **海马体（Hippocampus）**：情景记忆编码和检索的最关键脑区，负责绑定 What-Where-When 信息
- **前额叶皮层**：参与编码的组织和策略性检索
- **下顶叶**：与回忆的主观生动性相关

## 与其他记忆系统的关系

Tulving 提出三种记忆系统的层级关系：

```
程序性记忆（Procedural）  ← 最基础，关于"怎么做"
    ↑
语义记忆（Semantic）      ← 关于事实和概念（"狗是哺乳动物"）
    ↑
情景记忆（Episodic）      ← 关于个人经历（"我昨天看到一只狗"）
```

情景记忆建立在语义记忆之上。语义记忆不依赖情景记忆，但情景记忆依赖语义记忆。在个体发育上，情景记忆出现较晚、衰退较早。

情景记忆 + 语义记忆 = **陈述性记忆（Declarative Memory）**——即可用语言陈述的记忆。

## 当前研究进展（2024）

### 自知意识是否必要？

Tulving 认为自知意识是情景记忆的**必要条件**。但 2024 年，Felipe De Brigard 发表《Episodic Memory Without Autonoetic Consciousness》，直接挑战了这一立场：

- 自知意识作为一个构念缺乏效度——Tulving 在不同时期对其定义不一致
- 即使自知意识有效，它也不是情景记忆的必要条件
- 提议回到**功能/计算表征**的路径来定义情景记忆，将主观体验视为检索的伴随特征而非定义特征

### 场景构建框架

2024 年的研究提出了**场景构建框架（Scenario Construction Framework）**，认为情景记忆包含三个可分离的成分：
1. **情景记忆痕迹（EM Traces）**：存储在海马体中的事件核心
2. **语义信息（Semantic Information）**：辅助填充细节的通用知识
3. **场景构建（Scenario Construction）**：将痕迹与语义信息整合为完整场景的过程

这与"具象化核 + 重建"的观点高度吻合——记忆痕迹是核，场景构建是通过补充语义细节将核展开为完整经验的重建过程。

## 示例

### 回忆一次相遇

```
经历的事件：
  昨天下午在咖啡馆遇到一个朋友，聊了半小时。

存储的核：
  [主体: 我, 朋友] [位置: 咖啡馆] [时间: 昨天下午] [时长: 30min] [关系: 交谈]

回忆时的重建（每次可能不同）：
  第一次回忆 → "他穿着蓝色外套，坐在窗边"
  第二次回忆 → "他戴着帽子，我们聊的是旅行"
  核相同，但每次具象化填充的细节不同。
```
