# 比较

## 定义

比较是对两个输入向量在某一维度上做差分，提取差异或相似性的操作。

$$
D = W \cdot (A - B)
$$

其中：
- $A$、$B$ 为两个输入向量
- $A - B$ 为对应位置差分
- $W$ 为权重（标量或向量），用于调节各维度的敏感度
- $D$ 为输出差异值

## 可能的计算本质

比较属于[[../基础/抽象化|抽象化]]——对两个输入做差分运算，将高维的对象信息降为低维的差异或相似性描述。

## 性质

1. **反对称性**：交换输入顺序，差分结果反号。$A - B > 0$ 表示 A 相对于 B 偏大，则 $B - A < 0$ 表示 B 相对于 A 偏小。
2. **可调敏感性**：通过权重 W 放大或缩小差异。$W > 1$ 时差异被放大，$0 < W < 1$ 时差异被缩小。

## 示例

### 大小比较

```
A = 5
B = 3     →   比较(A, B) = 5 - 3 = 2    →    "A 偏大"
```

### 位置比较

A 在 B 的左边，则 A - B 在水平方向为负。
```
A = 2, B = 7（x 坐标）   →  比较(A, B) = 2 - 7 = -5   →   "A 在 B 左边"
```

### 相似性比较

对多个属性做加权差分，综合评估整体匹配程度。

```
A = [红, 圆, 大]
B = [橙, 圆, 大]

比较(A, B) = W₁(红 - 橙) + W₂(圆 - 圆) + W₃(大 - 大)
           = 0.3(1 - 0.8) + 0.3(0) + 0.4(0)
           = 0.06    →   "很相似"
```
