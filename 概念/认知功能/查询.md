# 查询

## 定义

查询是在一组候选中找出与查询向量最匹配的一个或几个的操作。

给定查询向量 $\mathbf{q}$ 和候选集合 $\mathbf{P} = \{\mathbf{p}_1, \mathbf{p}_2, \dots, \mathbf{p}_k\}$，查询的过程是：

1. 对每个候选 $\mathbf{p}_i$，计算它与 $\mathbf{q}$ 的匹配度
2. 选出匹配度最高（或满足阈值）的候选

$$
\mathbf{p}^* = \arg\max_{\mathbf{p}_i \in \mathbf{P}} \text{sim}(\mathbf{q}, \mathbf{p}_i)
$$

其中 $\text{sim}$ 为相似度函数（如点积、余弦、负距离等），$\mathbf{p}^*$ 为最匹配的候选。

## 可能的计算本质

查询可能涉及[[比较]]和选择。

## 性质

1. **依赖存储**：查询必须在已有候选集合上进行，不能从无中生有。
2. **匹配度驱动**：选择结果完全由匹配度函数决定，匹配度函数的选择决定了查询的行为特性。
3. **可带阈值**：可设定最低匹配度阈值，低于阈值时返回空（"未找到"）。

## 示例

### 记忆检索

给定一个部分记忆"红_的_果"，在记忆中查找最完整的匹配。

```
查询 q = [红, ?, 果]         候选 P = { p₁=[红, 圆, 果], p₂=[红, 方, 盒], p₃=[绿, 圆, 果] }

比较(q, p₁) = 0.92
比较(q, p₂) = 0.45
比较(q, p₃) = 0.51

→ 选出 p₁（"红圆果"）
```

### 最近邻查找

给定目标位置，在空间中找到最近的参照点。

```
查询 q = 位置 A                 候选 P = { 路口, 商店, 路灯 }

dist(q, 路口) = 10m
dist(q, 商店) = 50m
dist(q, 路灯) = 3m

→ 选出"路灯"（最近）
```
